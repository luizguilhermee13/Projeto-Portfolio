## 📌 Sobre o Projeto

Este portfólio foi desenvolvido com base no **Módulo 07** do curso **"HTML e CSS para Iniciantes"** da [Origamid](https://www.origamid.com/).

O objetivo desta etapa foi construir uma base sólida e funcional utilizando **HTML5 semântico** e **CSS3 moderno** (Grid Layout, Flexbox e variáveis CSS), aplicando as melhores práticas de acessibilidade e estrutura de código.

### 🚧 Status do Projeto: Em Desenvolvimento

Este projeto servirá como fundação para o meu portfólio pessoal e passará por constantes evoluções.

**Planejamento para as próximas versões:**

- 🎨 **Migração e Refatoração:** Reescrever o estilo utilizando **Tailwind CSS** para otimizar o fluxo de design.
- ⚛️ **Ecosistema React:** Componentizar a aplicação utilizando **React**, permitindo renderização dinâmica e gerenciamento de estado.
- 📄 **Novas Páginas & Seções:** Adicionar páginas dedicadas para detalhamento de projetos, formulário de contato dinâmico e visualização de experiências.
- ⚡ **Interatividade:** Implementar scripts em JavaScript/TypeScript para animações e controle de componentes da interface.
